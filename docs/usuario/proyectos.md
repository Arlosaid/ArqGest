# Proyectos — Guía de Usuario

## ¿Qué puedo hacer?
- Crear, ver y editar proyectos.
- Gestionar fases, tareas y archivos por proyecto.
- Visualizar y operar el tablero Kanban.

## Acceso rápido
- Menú → Projects.

---

## Crear un proyecto paso a paso
1. En la lista de Proyectos, haz clic en “Crear nuevo proyecto”.
2. Completa el nombre y la descripción (opcional).
3. Guarda. Serás llevado al detalle del proyecto.

Sugerencias:
- Usa nombres descriptivos y consistentes.
- Define desde el inicio las fases principales para ordenar el trabajo.

---

## Detalle del proyecto
- Pestañas principales: Fases, Tareas, Archivos, Kanban.
- Fases: estructura de tu flujo (p. ej., Backlog, En progreso, Hecho).
- Tareas: creación y edición de tareas asignadas a fases.
- Archivos: documentos por fase.
- Kanban: tablero visual para mover tareas entre columnas.

---

## Tablero Kanban
1. Entra a la pestaña Kanban.
2. Arrastra las tarjetas de tareas entre columnas para cambiar su estado/fase.
3. Abre una tarjeta para ver/editar detalles.

Buenas prácticas:
- Revisa el tablero a diario para mantener el flujo.
- Evita saturar columnas intermedias: promueve el avance hacia “Hecho”.
