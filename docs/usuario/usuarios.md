# Usuarios — Guía de Usuario

## ¿Qué puedo hacer?
- Ver la lista de usuarios de tu organización.
- Si eres administrador de organización, crear, editar, desactivar o eliminar usuarios.

## Acceso rápido
- Menú → Users.

---

## Crear un usuario (solo administradores de organización)
1. Haz clic en “Crear usuario”.
2. Completa nombre, apellido y correo electrónico.
3. Define si será administrador de organización (opcional).
4. Guarda para enviar credenciales o definir contraseña inicial.

---

## Editar, desactivar o eliminar
1. Abre el detalle del usuario desde la lista.
2. Edita los campos necesarios y guarda.
3. Para desactivar, cambia el estado “Activo”. Para eliminar, usa la acción correspondiente.

---

## Buenas prácticas
- Mantén actualizados los datos de los usuarios.
- Usa correos válidos: ayudan con la recuperación de cuenta y comunicaciones.
