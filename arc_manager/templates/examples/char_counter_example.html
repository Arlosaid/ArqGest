Ejemplos de Contadores de Caracteres

Esta página muestra diferentes ejemplos de uso del sistema de contadores de caracteres.

Campo de Texto Básico
Máximo 100 caracteres. Sea claro y específico.
Código HTML: 
<input type="text" 
       class="form-control"
       data-char-counter="true"
       data-max-length="100">
Título de Tarea (120 caracteres)
Nombres de Usuario (50 caracteres)
Formulario Completo
Prueba de Estados Visuales
Instrucciones: Escribe en este campo para ver cómo cambian los colores:
  • 0-74% → Color gris (normal)
  • 75-89% → Color azul (informativo)
  • 90-99% → Color amarillo (advertencia)
  • 100%+ → Color rojo (error)
Guía Rápida de Implementación
Para agregar un contador a cualquier campo:
  1. Agrega los atributos al campo: 
    data-char-counter="true"
data-max-length="100"
  2. En formularios Django, usa el widget: 
    widgets = {
    'nombre': forms.TextInput(attrs={
        'class': 'form-control',
        'data-char-counter': 'true',
        'data-max-length': '100'
    })
}
  3. El contador se inicializa automáticamente.
    No necesitas JavaScript adicional.
  4. Para contenido dinámico (modales, AJAX): 
    // Llamar después de cargar contenido nuevo
window.reinitCharCounters();
Tip: Los archivos CSS y JS ya están incluidos en base.html. No necesitas importarlos manualmente en tus templates.
