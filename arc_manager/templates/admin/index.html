Guía Rápida

Agregar un Usuario

  1. Clic en "Crear Usuario" arriba
  2. Llenar email, nombre y apellido
  3. Seleccionar la organización
  4. Guardar - se enviará contraseña por email

Crear Organización

  1. Clic en "Nueva Organización"
  2. Asignar nombre y activar
  3. Guardar la organización
  4. Luego crear suscripción para ella

Aprobar Upgrade

  1. Ir a notificaciones de Upgrades
  2. Revisar solicitud del cliente
  3. Clic en "Aprobar" o "Rechazar"
  4. El plan cambia automáticamente

Procesar Renovación

  1. Ir a notificaciones de Renovaciones
  2. Verificar pago recibido
  3. Clic en "Aprobar"
  4. La suscripción se extiende automáticamente
