¿Cómo procesar una solicitud de upgrade?

Pasos para procesar

  1. Verifica el pago: Confirma que el cliente haya realizado el pago del upgrade.
  2. Revisa los datos: Verifica la organización, plan actual y plan solicitado.
  3. Aprueba o rechaza: Usa los botones de la lista o cambia el estado.
  4. El sistema hace el resto: Al aprobar, el plan se actualiza automáticamente.
Aprobar = Cambia el plan automáticamente Rechazar = Mantiene el plan actual
🔮 Automatización

Al aprobar, el sistema automáticamente: cambia el plan, recalcula la fecha de vencimiento y registra el pago. ¡No tienes que hacer nada más!
